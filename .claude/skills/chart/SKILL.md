# Чарты и музыка BEATROOT

Дизайн-контекст — [GDD.md](../../../GDD.md) §10. Инструмент — `tools/chartgen/`.

**Сам механизм — общий, а не наш.** Он вынесен в личный скилл
`genmusic-pipeline` вместе с каталогом провалов и картой реализации. Здесь
остаётся то, что специфично для BEATROOT: стихии, грейды, типы нот, правила
разметки с нашими числами. Если чинишь лестницу сложности, мелодию, которая
не запоминается, или собираешь такой же конвейер в другом проекте — смотри туда.

## Главный принцип

**Партитура — это данные, из которых рендерится и звук, и карта нот.**

Сетка совпадает по построению, детекция BPM не нужна вовсе. Это же даёт весь
объём контента: 10 мотивов × 5 стихий × 6 грейдов = **300 боевых треков**.

## Что где лежит

```
data/motifs.json      10 отобранных мотивов — источник истины, НЕ перегенерируется
music/*.ogg           300 боевых треков, {стихия}_{мотив}_{грейд}_{BPM}.ogg
music/ui/*.ogg        8 петель экранов
music/glade/*.ogg     20 подсказок полян (5 на каждый тип)
music/cue/*.ogg       3 джингла: заставка, победа, поражение
charts/*.json         306 карт нот, имя совпадает с именем аудио
```

`demo_disco` и `farm_folk` — легаси-треки со старыми сложностями
`easy/normal/hard`. На них держатся обучение и танец растению; трогать
выверенный онбординг ради единообразия имён смысла нет.

## Стихии и грейды

Пять стихий GDD §5, за каждой закреплён свой жанр — игроку показывается
стихия, в коде и в именах файлов стоит жанр:

| стихия | жанр | базовый BPM | ведущий | бас |
|---|---|---|---|---|
| Камень | `rock` | 104 | гитара | квинты |
| Солнце | `disco` | 120 | лид | октавные восьмые |
| Листва | `folk` | 100 | щипок | половинки |
| Искра | `electro` | 128 | пила | синкопы шестнадцатыми |
| Ветер | `latin` | 108 | щипок | тумбао |

Хип-хопа в списке нет намеренно: на этом синтезе разреженный бит и длинный саб
оставляли трек почти пустым, а «почти пустой» для ритм-игры означает
«не по чему попадать».

**Сложность = грейд монстра**, отдельной оси easy/normal/hard у боевой музыки
нет. От обычного к легендарному темп растёт ровно вдвое, но это ремикс,
а не перемотка: на верхнем грейде мелодия растягивается вдвое в долях
и звучит с прежней скоростью, ударные уходят в half-time, а освободившаяся
сетка идёт на фактуру.

## Числа лестницы

| грейд | ×BPM | нот в окне 2 сек | нот в чарте | мс между нотами |
|---|---|---|---|---|
| `common` | 1.00 | 4 | 35 | 891 |
| `uncommon` | 1.15 | 5 | 49 | 588 |
| `rare` | 1.32 | 6 | 67 | 453 |
| `unique` | 1.52 | 7 | 74 | 402 |
| `epic` | 1.74 | 8 | 89 | 325 |
| `legendary` | 2.00 | 9 | 107 | 280 |

**Потолок не растёт вместе с темпом.** Легендарный трек играет вдвое быстрее,
но руки у игрока те же.

Верхняя ступень — 4.5 ноты в секунду, и это ниже прежних восьми из GDD §10.3
не из осторожности. Пока сложность выбирал игрок, восемь были верхней полкой
для тех, кто её захотел. Теперь сложность навязана грейдом встреченного
монстра, ребёнок не может отказаться от эпика, а приручение по §6.3
гарантировано и требует победы. Значит верхний грейд обязан **проходиться**,
а не «быть доступным».

## Команды

```bash
cd tools/chartgen

# что вообще есть
uv run chartgen list

# кандидаты в мотивы: по 3 на каждый характер, слушать ушами
uv run chartgen motifs --audition 3
uv run chartgen motifs --freeze 0:1 1:20 2:37 ...   # характер:сид

# вся матрица: аудио + чарты
uv run chartgen build-all
uv run chartgen build-all --motif zarya --grade common --charts-only

# джинглы, петли экранов, подсказки полян
uv run chartgen cues

# легаси-трек со старыми сложностями
uv run chartgen build demo_disco

# внешнее аудио
uv run chartgen analyze path/to/track.mp3
uv run chartgen autochart path/to/track.mp3 --bpm 128 --genre rock

# проверка: без аргумента обходит весь каталог
uv run chartgen validate
```

`build-all` и `validate` возвращают **ненулевой код** при любом замечании.

## Формат чарта

JSON в `charts/`, позиции нот — **в долях, не в секундах**. Секунды считаются
в рантайме от BPM и offset, иначе чарт ломается при смене темпа.

```json
{
  "id": "disco_zarya",
  "genre": "disco",
  "bpm": 240.0,
  "offset": 0.0,
  "difficulty": "legendary",
  "audio": "res://music/disco_zarya_legendary_240.ogg",
  "notes": [{"beat": 4.0, "type": "beat"}],
  "monster_pattern": [{"beat": 12.0, "action": "windup"}]
}
```

Типы нот и кнопки (GDD §4.2). Низ экрана поделён надвое: правая половина —
обычный бит, левая — особый. Дорожка вычисляется из типа в `data/note_rules.gd`
и в чарте не хранится:

| Тип | Кнопка | Что делает |
|---|---|---|
| `beat` | обычная | копит серию, урона не наносит |
| `attack` | **особая** | единственный источник урона по Настрою, в конце серии |
| `skill` | **особая** | спецдвижение гуардиана по его стихии |
| `shield` | **особая** | блок атаки монстра; обычной кнопкой не берётся |
| `snack` | любая | зелье: особой — выпить, обычной — сберечь |

**BPM есть в имени файла, поэтому путь к чарту не собирается формулой.**
`ChartLoader` строит индекс каталога при первом обращении. Держать таблицу
темпов ещё и в GDScript нельзя: она разойдётся с генератором на первой правке.

## Правила разметки (проверяются `validate`)

Нарушение любого — чарт нечестный или нечитаемый. Правила продублированы
в `tools/chart_forge/chart_validator.gd`: генератор проверяет при создании,
редактор — при каждой правке. **Дубль намеренный и правится в обоих местах.**

1. **Щит всегда телеграфируется.** Каждой ноте `shield` предшествует `windup`
   монстра минимум за 2 доли. Игрок обязан видеть замах раньше ноты.
2. **Два щита подряд ближе 2 долей — запрещено.** Ребёнок не успеет.
3. **Плотность:** не больше N нот в окне длиной **2 секунды**, N по грейду
   из таблицы выше. Окно именно двухсекундное: на односекундном ноты в окне
   целые, и «3.0» с «3.5» становятся одним ограничением — грейды схлопываются
   попарно.
4. **Первые 2 такта — не плотнее одной ноты на долю.** Вход в бой мягкий.
5. **Никакой ноты раньше 1 такта от старта.** Игроку нужно поймать ритм.
6. **Щит не совпадает по времени с нотой другого типа.**
7. **Перед атакой — минимум 3 ноты без паузы.** Атака бьёт только в конце
   чистой серии, и поставленная в начало связки не сработает никогда.

## Неигровая музыка

Собирается командой `cues`, чартов не имеет — под неё не играют.

**У каждого экрана своя петля**, и это навигация, а не украшение: игрок
понимает, где находится, не глядя. Восемь экранов, у каждого свой мотив, темп
и тембр. Калибровка намеренно без музыки — там игрок стучит под метроном,
и фон сломал бы сам замер.

**Поляны — 5 вариантов на каждый из четырёх типов** `Glade.Type`. Варианты
выписаны нотами, а не получены транспозицией: общим у них остаётся жест —
бой идёт вверх и повисает, костёр оседает к тонике, встреча обрывается
на неустойчивой ступени.

**Джингл поражения не минорный.** Монстр убегает, а не побеждает игрока
(§4.2.2), и дружба растёт даже при неудаче (§6.1). Печальный аккорд врал бы
про механику: фраза спускается, но разрешается в мажорную терцию.

## Godot-сторона

Чарт читается в `ChartData` (Resource) через `ChartLoader.load_by_id(id, grade)`.
Время в бою берётся **только** у `Conductor` —
`get_playback_position() + get_time_since_last_mix() - get_output_latency()`.
Никогда не считай тайминг нот через `delta`.

После добавления новых `.ogg` прогоняй импорт, иначе движок их не видит:

```bash
"/c/Program Files/Godot_v4.6.2-stable_win64.exe/Godot_v4.6.2-stable_win64_console.exe" --headless --path E:/v2 --import
```
