# Чарты и музыка BEATROOT

Дизайн-контекст — [GDD.md](../../../GDD.md) §10. Инструмент — `tools/chartgen/`.

## Два источника треков

**1. Синтезированный (ground truth).** Трек описан как данные в `songs/*.py`, аудио
рендерится из этого же описания. Чарт выводится напрямую из нот мелодии — сетка
идеальна по построению, детекция не нужна. **Используй для отладки тайминга и Фазы 0.**

**2. Внешний (mp3/wav/ogg).** BPM и онсеты определяются анализом, дальше чарт правится
руками. Точность зависит от стабильности темпа в записи.

Если задача — «проверить, что ритм-ядро работает», всегда бери синтезированный трек:
любое расхождение тогда точно в коде игры, а не в разметке.

## Команды

```bash
cd tools/chartgen

# список доступных песен
uv run chartgen list

# рендер аудио + чарты всех сложностей → res://music/ и res://charts/
uv run chartgen build demo_disco

# анализ внешнего файла
uv run chartgen analyze path/to/track.mp3

# черновой чарт из внешнего файла (дальше правится руками)
uv run chartgen autochart path/to/track.mp3 --bpm 128 --genre rock

# проверка играбельности существующего чарта
uv run chartgen validate ../../charts/demo_disco_normal.json
```

## Формат чарта

JSON в `charts/`, позиции нот — **в долях (beats), не в секундах**.
Секунды считаются в рантайме от BPM и offset, иначе чарт ломается при смене темпа.

```json
{
  "id": "demo_disco",
  "genre": "disco",
  "bpm": 120.0,
  "offset": 0.0,
  "difficulty": "normal",
  "notes": [{"beat": 4.0, "type": "beat"}],
  "monster_pattern": [{"beat": 12.0, "action": "windup"}]
}
```

Типы нот и кнопки (GDD §4.2). Низ экрана поделён надвое: правая половина —
обычный бит, левая — особый. Дорожка вычисляется из типа в `data/note_rules.gd`
и в чарте не хранится:

| Тип | Кнопка | Что делает |
|---|---|---|
| `beat` | обычная | копит серию, урона не наносит |
| `attack` | **особая** | единственный источник урона по Настрою, в конце серии |
| `skill` | **особая** | спецдвижение гуардиана по его стихии |
| `shield` | **особая** | блок атаки монстра; обычной кнопкой не берётся |
| `snack` | любая | зелье: особой — выпить, обычной — сберечь |

Сложность задаётся ГРЕЙДОМ: `common`…`legendary`, и каждый следующий —
это отдельный ремикс в более высоком темпе, а не подкрученные числа
(GDD §10.1.1). Старые `easy/normal/hard` остались только у демо-треков.

## Правила разметки (проверяются `validate`)

Нарушение любого — чарт нечестный или нечитаемый:

1. **Щит всегда телеграфируется.** Каждой ноте `shield` предшествует `windup` монстра
   минимум за 2 доли. Игрок обязан видеть замах раньше, чем появится нота.
2. **Два щита подряд ближе 2 долей — запрещено.** Ребёнок не успеет.
3. **Плотность** по грейду: common ≤ 2 ноты/сек, uncommon ≤ 3, rare ≤ 4,
   unique ≤ 5, epic ≤ 6.5, legendary ≤ 8.
4. **Первые 2 такта — не сложнее одной ноты на долю.** Вход в бой должен быть мягким.
5. **Никакой ноты раньше 1 такта от старта трека.** Игроку нужно поймать ритм.
6. **Щит не совпадает по времени с нотой другого типа.**
7. **Перед атакой — минимум 3 ноты без паузы.** Атака бьёт только в конце
   чистой серии, и поставленная в начало связки она не сработает никогда.

## Как добавить синтезированную песню

Создай `tools/chartgen/songs/<id>.py` по образцу `demo_disco.py`. Песня — это данные:
BPM, длина, дорожки (`kick`, `snare`, `hat`, `bass`, `lead`) со списками нот.
Мелодия ведущей дорожки автоматически становится источником нот чарта.

Держи мелодию в пентатонике — она звучит приятно почти при любом сочетании нот,
что важно, когда трек генерируется, а не сочиняется вручную.

## Godot-сторона

Чарт читается в `ChartData` (Resource). Время в бою берётся **только** у `Conductor` —
`get_playback_position() + get_time_since_last_mix() - get_output_latency()`.
Никогда не считай тайминг нот через `delta`.
